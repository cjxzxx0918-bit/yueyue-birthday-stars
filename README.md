# Yueyue Birthday Stars ✦

一个可离线播放的生日祝福动画：星光聚成三层生日蛋糕，再由同一组粒子汇成「悦悦生日快乐」。

**在线观看：[yueyue-birthday-stars.pages.dev](https://yueyue-birthday-stars.pages.dev/)**

链接不包含账号名，无需登录。可复制到微信，打开后点击「开启生日惊喜」。

![粒子蛋糕与生日祝福](assets/preview.jpg)

## 体验

打开 `index.html`，点击「开启生日惊喜」。约 30 秒的动画包含蛋糕成形、缓慢旋转、粒子散开、生日祝福文字成形和轻微星光烟花。结尾文字保持显示，可重播。

经典《生日快乐》旋律采用轻柔音乐盒编曲，由 Web Audio 合成，包含两遍旋律、分解和弦与混响。声音需要在点击开始后播放。

支持手机、电脑、静音、暂停和重播。切换到其他标签页时，会同时暂停动画与音乐。页面没有外部图片、字体、脚本或音频依赖。

## 使用

直接下载并用浏览器打开 `index.html`，或把它发布到任意静态网页托管服务。无需安装依赖或构建。

推荐使用 Chrome、Edge 或 Safari。手机分享请发送已托管网页的 HTTPS 链接。

## 自定义

文件内的 `CONFIG` 对象控制粒子名字、生日祝福文字、结尾祝福与时长。修改名字时，也可同步修改页面标题、开场文字、页眉及无障碍描述。

粒子蛋糕、转场和音乐编曲均在同一个 HTML 文件中，方便修改和再创作。

## 验证

已在实际浏览器中检查电脑、手机竖屏及横屏布局，检查动画成形、文字可读性、声音开关、暂停同步及重播。不同手机和微信内置浏览器的实际表现仍需按设备验证。
